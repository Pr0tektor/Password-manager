# Менеджер паролей

**Ваши пароли. Ваш ключ. Ваш контроль.**

Личное хранилище для логинов, паролей и важных заметок — с понятным русским интерфейсом и шифрованием прямо в браузере. Соберите доступы к своим аккаунтам в одном месте, находите нужную запись через поиск и создавайте новые пароли встроенным генератором.

Перенесите сохранённые пароли из Chrome через CSV: перед импортом приложение покажет количество новых записей и пропустит точные дубликаты. Для переноса хранилища на другое устройство скачайте зашифрованную резервную копию.

- **Хранилище на вашем устройстве.** Данные сохраняются в браузере, приложение не отправляет пароли на сервер.
- **Один мастер-пароль для доступа.** Записи зашифрованы с помощью AES-256-GCM; мастер-пароль не сохраняется.
- **Меньше рутины.** Быстрый поиск, копирование логинов и паролей, редактирование записей и генератор паролей длиной 12–64 символа.
- **Контроль над копиями.** Экспорт и восстановление зашифрованного хранилища, импорт из Chrome и автоматическая блокировка.

Работает без регистрации, подписки, аналитики и сторонних библиотек. Для локального запуска нужен Node.js 22 или новее; установка зависимостей не требуется.

## Запуск на Windows

Нужен Node.js 22 или новее. Откройте `Запустить.cmd` и перейдите по адресу **http://localhost:4173**. Пока пользуетесь приложением, оставляйте окно сервера открытым. Для остановки нажмите Ctrl+C. Установка зависимостей не требуется.

Альтернативно из папки проекта:

```sh
npm start
```

Открытие `index.html` двойным щелчком не поддерживается: модули и Web Crypto требуют localhost или HTTPS. Локальный сервер слушает только 127.0.0.1, не публикует приложение в сети и не получает содержимое хранилища.

## Что умеет

- Создание и разблокировка хранилища мастер-паролем (при создании — не менее 12 символов).
- Добавление, просмотр, редактирование и удаление записей: название, логин, пароль, сайт и заметка.
- Поиск по названию, логину и сайту. Пароли не участвуют в поиске.
- Копирование логина/пароля; показ пароля в редакторе на 15 секунд.
- Криптографически случайные пароли длиной 12–64 символа, с выбором наборов символов.
- Экспорт зашифрованной копии JSON. Импорт в открытое хранилище объединяет записи; точные дубликаты пропускаются, изменённые версии сохраняются отдельно. При импорте остаётся мастер-пароль текущего хранилища.
- Восстановление из копии на экране создания пустого хранилища с мастер-паролем копии.
- Импорт CSV из Chrome с предварительным подсчётом записей, пропуском точных дубликатов и записей без пароля; поддерживаются кавычки, запятые, переносы строк, UTF-8 BOM и заметки.
- Ручная блокировка, блокировка после 5 минут бездействия и немедленно при скрытии/закрытии вкладки. Неоконченные формы очищаются при блокировке.
- Сброс локального хранилища на экране входа с явным подтверждением словом «УДАЛИТЬ». Эта операция безвозвратна; сначала сохраните резервную копию.
- Защита от сохранения устаревшей версии из другой вкладки: Web Locks и повторная проверка данных перед записью.
- Понятные ошибки при неверном пароле, повреждённой копии, запрещённом хранилище или превышении квоты.

## Как перенести пароли из Chrome

1. В Chrome откройте меню → **Пароли и автозаполнение → Менеджер паролей Google → Настройки**.
2. В разделе экспорта паролей нажмите **Скачать файл** и подтвердите действие средствами вашей ОС.
3. Откройте это приложение, создайте или разблокируйте хранилище и нажмите **Импорт из Chrome**.
4. Выберите CSV-файл. Приложение покажет количество новых записей, дубликатов и строк без пароля. До нажатия **Импортировать** данные не сохраняются.
5. Проверьте импортированные записи, скачайте зашифрованную резервную копию и удалите незашифрованный CSV с устройства безопасным для вас способом. Приложение не удаляет исходный файл автоматически.

CSV обрабатывается только локально; файл и пароли не отправляются на GitHub или сервер. Обязательны колонки `url`, `username`, `password`; `name`, `note` и `notes` необязательны. Лимит — 4 МБ и 2000 записей в файле. Неверный формат или слишком длинное поле отменяют весь импорт, не изменяя существующие записи. Пароли сохраняют начальные/конечные пробелы. Одинаковые записи пропускаются; разные пароли одного аккаунта сохраняются отдельными записями. Passkeys, платёжные данные и адреса не импортируются.

[Официальная инструкция Google по экспорту паролей](https://support.google.com/chrome/answer/13068232?hl=ru).

## Как сохраняются данные

В `localStorage` по ключу `password-manager.v1` хранится только зашифрованный конверт. Все поля записей, включая названия, логины и заметки, шифруются вместе. Мастер-пароль не сохраняется. Ключ AES-256-GCM получается через PBKDF2-HMAC-SHA-256 с 600 000 итераций и случайной солью 16 байт. Каждое сохранение использует новый случайный IV 12 байт и тег аутентификации 128 бит. Формат и версия привязаны к ciphertext через additional authenticated data. CryptoKey неэкспортируемый.

Схема импорта проверяется до расшифровки; параметры KDF фиксированы, чтобы чужой файл не мог навязать огромный объём вычислений. Лимит копии — 4 МБ, записей — 2000; квота браузера может закончиться раньше. Ошибка записи не заменяет предыдущую копию в памяти или в хранилище.

Приложение не загружает внешние шрифты, иконки или библиотеки. CSP запрещает сетевые запросы из приложения, встраивание объектов и отправку форм; локальный сервер дополнительно запрещает встраивание страницы во фрейм. Пользовательские значения выводятся через textContent и поля форм, без интерпретации HTML.

## Что важно знать

Это первая версия собственного менеджера паролей, **без независимого аудита безопасности**. Перед хранением важных доступов нужен отдельный аудит; для первых проверок используйте тестовые записи.

- Забытую мастер-фразу восстановить нельзя. Выберите длинную уникальную фразу и сохраните её безопасным способом отдельно.
- Очистка данных браузера, удаление профиля, работа в приватном режиме или переустановка могут привести к потере данных. **Скачивайте резервную копию после изменений** и проверяйте восстановление.
- Данные привязаны к конкретному браузеру и origin (протокол, имя хоста и порт). `localhost:4173` и `127.0.0.1:4173` — разные хранилища. Для переноса используйте экспорт/импорт. При последующей публикации локальные данные сами на сайт не переедут.
- Пока хранилище открыто, расшифрованные записи и ключ находятся в памяти процесса. JavaScript не гарантирует полное стирание строк из памяти. Блокировка убирает доступ к ключу/записям и очищает формы; вредоносные расширения, заражённая ОС или подмена файлов приложения остаются вне защиты.
- Буфер обмена после копирования автоматически не очищается, чтобы не перезаписать другие скопированные данные. История буфера обмена/синхронизация ОС могут сохранять пароли.
- Защита от перебора зависит прежде всего от мастер-фразы. Локальную зашифрованную копию можно атаковать вне приложения; серверного ограничения попыток нет.
- Если Web Locks не поддерживается браузером, остаются проверки версии, но запись в двух вкладках одновременно не имеет полной гарантии атомарности. Используйте один экземпляр приложения.
- Резервные копии зашифрованы, но тоже должны храниться безопасно. Нет двухфакторной аутентификации, автозаполнения и синхронизации устройств.

## Проверки

```sh
npm run check
npm test
```

Используется встроенный тестовый раннер Node.js. Проверяются шифрование/расшифровка Unicode, неверные пароли, подмена ciphertext, случайность IV/соли, генератор, валидация копий, CRUD, импорт/объединение, ошибки сохранения, конфликт вкладок, отмена при блокировке и HTTP-заголовки сервера. Это функциональные проверки, не аудит криптографии.
