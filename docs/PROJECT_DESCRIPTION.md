# Описание для GitHub / GitHub description

## About — двуязычная короткая версия / bilingual short version

Менеджер паролей / Password Manager — RU/EN, AES-256-GCM, импорт Chrome, установка PWA и офлайн-доступ. Локальное хранилище и зашифрованные копии / Local vault and encrypted backups. Google Drive — после настройки / after setup.

## Русский

Ваши пароли. Ваш ключ. Ваш контроль. Личное зашифрованное хранилище с русским и английским интерфейсом, переносом паролей из Chrome, генератором и установкой как PWA. Работайте с записями без сети после первой загрузки и сохраняйте зашифрованные резервные копии на устройстве или в Google Drive после настройки подключения.

## English

Your passwords. Your key. Your control. A personal encrypted vault with Russian and English interfaces, Chrome password import, a password generator and PWA installation. Access your entries offline after the first successful setup and keep encrypted backups on your device or in Google Drive once configured.

Google Drive requires an OAuth Client ID configured once by the app owner. This project has not undergone an independent security audit. / Для Drive владелец приложения один раз настраивает OAuth Client ID. Независимый аудит безопасности не выполнен.
