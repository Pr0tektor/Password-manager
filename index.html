    Удалить запись?

    Вернуть её можно только из ранее сохранённой резервной копии.

    Импорт резервной копии

    Записи будут добавлены в хранилище. Существующие записи сохранятся.

    Импорт из Chrome

    В Chrome откройте «Менеджер паролей Google» → «Настройки» → «Экспортировать пароли» и скачайте файл CSV.

    Выберите файл, чтобы проверить записи перед импортом.

    Файл обрабатывается только в браузере. Существующие записи сохранятся, точные дубликаты пропустим.

    CSV содержит незашифрованные пароли. После проверки импорта удалите этот файл с устройства и сохраните зашифрованную резервную копию.

    Сбросить хранилище?

    Все записи на этом устройстве будут безвозвратно удалены. Доступ к ним сохранится только в ранее скачанной резервной копии.

    Чтобы сохранить копию, отмените сброс, откройте хранилище и скачайте её.
