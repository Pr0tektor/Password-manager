    Установить приложение

    Приложение откроется в отдельном окне с иконкой на вашем устройстве.

    В Chrome или Edge откройте меню браузера и выберите установку приложения. На iPhone или iPad в Safari нажмите «Поделиться», затем «На экран Домой».

    Резервная копия в Google Drive

    В Google Drive будет сохранена только зашифрованная копия. Мастер-пароль остаётся на этом устройстве.

    Первичная настройка Google Drive

    Один раз создайте OAuth Client ID для веб-приложения в Google Cloud. Подробные шаги приведены в руководстве из комплекта.

    Приложение запрашивает доступ только к файлам, которые вы создадите или выберете через него. Копии сохраняются вручную; автоматическая синхронизация не включена.

    Для восстановления скачайте копию из Google Drive и используйте «Импортировать копию» в хранилище.

      Удалить запись?

      Вернуть её можно только из ранее сохранённой резервной копии.

      Импорт резервной копии

      Записи будут добавлены в хранилище. Существующие записи сохранятся.

      Импорт из Chrome

      В Chrome откройте «Менеджер паролей Google» → «Настройки» → «Экспортировать пароли» и скачайте файл CSV.

      Выберите файл, чтобы проверить записи перед импортом.

      Файл обрабатывается только в браузере. Существующие записи сохранятся, точные дубликаты пропустим.

      CSV содержит незашифрованные пароли. После проверки импорта удалите этот файл с устройства и сохраните зашифрованную резервную копию.

      Сбросить хранилище?

      Все записи на этом устройстве будут безвозвратно удалены. Доступ к ним сохранится только в ранее скачанной резервной копии.

      Чтобы сохранить копию, отмените сброс, откройте хранилище и скачайте её.
