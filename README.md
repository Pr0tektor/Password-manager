# Менеджер паролей

**Ваши пароли. Ваш ключ. Ваш контроль.**

**Русский** | [English](README.en.md) · [Подробное руководство](docs/USER_GUIDE_RU.md) · [Двуязычная инструкция для печати](docs/guide.html)

**[Открыть приложение →](https://pr0tektor.github.io/Password-manager/)** · [Инструкция онлайн](https://pr0tektor.github.io/Password-manager/docs/guide.html#ru)

Личное пространство для логинов, паролей и важных заметок. Шифрование происходит прямо в браузере, а мастер-пароль знаете только вы. Перенесите доступы из Chrome, находите нужный аккаунт через поиск и создавайте новые пароли встроенным генератором.

**English:** Your passwords. Your key. Your control. A local encrypted vault with Russian/English interfaces, Chrome import, PWA offline access and optional encrypted Google Drive backups. [Read the English description and setup guide](README.en.md).

## Возможности

- **Зашифрованное локальное хранилище:** AES-256-GCM; мастер-пароль не сохраняется и не отправляется в сеть.
- **Русский и английский интерфейс:** переключение языка без изменения ваших записей.
- **Установка как PWA:** иконка приложения, отдельное окно и работа без сети после успешной подготовки офлайн-кэша.
- **Импорт из Chrome:** предпросмотр CSV, пропуск точных дубликатов и перенос заметок.
- **Удобство каждый день:** поиск, редактирование, копирование, генератор паролей длиной 12–64 символа и автоматическая блокировка.
- **Копии под вашим контролем:** зашифрованные JSON-файлы и дополнительное ручное сохранение в ваш Google Drive.
- **Инструкции в комплекте:** подробные руководства на русском и английском, настройка, восстановление и решение проблем.

Без подписки, аналитики и установки дополнительных библиотек. Вход Google загружается только при открытии настроенной функции Drive. В офлайн-кэше хранятся файлы приложения, а не пароли или токены Google.

## Быстрый старт

Откройте **[Password Manager](https://pr0tektor.github.io/Password-manager/)** и установите приложение из браузера. **Node.js и открытое окно сервера пользователю не нужны.** Версия размещена на GitHub Pages через HTTPS; пароли сохраняются в зашифрованном виде в вашем браузере.

1. Откройте адрес приложения в Chrome, Edge или Safari.
2. Выберите язык и создайте хранилище.
3. Нажмите **Установить** и дождитесь сообщения о готовности офлайн-режима.
4. Установите приложение через меню браузера; на iPhone/iPad используйте **Поделиться → На экран Домой**.
5. Запускайте по иконке. После успешного кэширования приложение открывается без сети, пока браузер сохраняет его данные. Сохраняйте зашифрованные резервные копии после важных изменений.

### Локальный запуск для разработки

Скачайте и распакуйте репозиторий. При установленном Node.js 22 или новее откройте **Запустить.cmd** / **Start.cmd** либо выполните:

```sh
npm start
```

Откройте **http://localhost:4173**. Сервер нужен для первой локальной загрузки и получения обновлений; после готовности офлайн-кэша проверьте запуск без него с тестовыми данными.

Двойной щелчок по index.html не поддерживается. Localhost доступен только на том устройстве, где запущен сервер. На телефоне используйте [публичную HTTPS-версию](https://pr0tektor.github.io/Password-manager/). Для переноса локальных записей на опубликованный адрес экспортируйте и импортируйте зашифрованную копию: данные между адресами не переносятся автоматически.

## Google Drive: одна настройка для приложения

Владелец приложения один раз настраивает публичный **Google OAuth Client ID**. Затем каждый пользователь подключает свой Google-аккаунт; создавать Cloud-проект каждому клиенту не нужно. В комплекте config.mjs оставлен без ID. Его можно указать в общей сборке либо в диалоге настройки Google Drive для своей локальной копии.

На Drive отправляется только зашифрованный JSON, в папку **Password Manager Backups**. Каждое сохранение создаёт новый файл; автоматической синхронизации нет. Приложение запрашивает ограниченное разрешение **drive.file**, а токен доступа держит только в памяти страницы. Для восстановления скачайте файл из Drive и импортируйте как обычную копию.

[Пошаговая настройка и решение проблем](docs/USER_GUIDE_RU.md#13-google-drive-первичная-настройка-владельцем)

Реальный вход и загрузка требуют вашего Client ID и авторизации аккаунта. Для сборки без настроенного ID не заявляется проверка полного подключения к реальному Google-аккаунту.

## Перед использованием важных паролей

Это первая версия **без независимого аудита безопасности**. Начните с тестовых данных. Забытый мастер-пароль восстановить нельзя. Очистка данных сайта, удаление профиля браузера или приложения вместе с данными могут удалить хранилище. Установка PWA и подключение Google не заменяют проверенные резервные копии.

Данные привязаны к точному браузерному профилю и адресу приложения. При смене браузера, хоста или порта используйте экспорт/импорт. Буфер обмена не очищается автоматически. Заражённая ОС, вредоносные расширения и подмена кода остаются вне защиты приложения.

[Подробно о сохранности и восстановлении](docs/USER_GUIDE_RU.md#15-блокировка-удаление-и-сохранность)

## Техническая информация

HTML/CSS/JavaScript без сборки и npm-зависимостей. Web Crypto: AES-256-GCM, PBKDF2-HMAC-SHA-256 с 600 000 итераций, случайная соль 16 байт и новый IV 12 байт при сохранении. Формат копий совместим с версией 1.0. Service worker кэширует только явно перечисленные публичные файлы; запросы Google и файлы хранилища исключены.

```sh
npm run check
npm test
```

Функциональные проверки охватывают шифрование, записи, объединение копий, CSV, ошибки сохранения, отмену при блокировке, локализацию, PWA и запросы Drive с имитацией API. Они не заменяют аудит безопасности. Ограничения, обновления и заголовки для собственного хостинга описаны в [полном руководстве](docs/USER_GUIDE_RU.md).
