## About — двуязычная короткая версия / bilingual short version

Менеджер паролей / Password Manager — RU/EN, AES-256-GCM, пароли и несколько API-ключей / passwords and multiple API keys, импорт Chrome, PWA и офлайн-доступ. Локальное хранилище и зашифрованные копии / Local vault and encrypted backups. Google Drive — после настройки / after setup.

## Русский

Ваши пароли. Ваш ключ. Ваш контроль. Личное зашифрованное хранилище с русским и английским интерфейсом, несколькими именованными API-ключами в каждой записи, переносом паролей из Chrome, генератором и установкой как PWA. Копируйте значения аккуратным значком двух листов, работайте без сети после первой загрузки и сохраняйте зашифрованные резервные копии на устройстве или в Google Drive после настройки подключения.

## English

Your passwords. Your key. Your control. A personal encrypted vault with Russian and English interfaces, multiple named API keys per entry, Chrome password import, a password generator and PWA installation. Copy values with a compact two-sheet icon, access your entries offline after the first successful setup and keep encrypted backups on your device or in Google Drive once configured.

Google Drive requires an OAuth Client ID configured once by the app owner. This project has not undergone an independent security audit. / Для Drive владелец приложения один раз настраивает OAuth Client ID. Независимый аудит безопасности не выполнен.
